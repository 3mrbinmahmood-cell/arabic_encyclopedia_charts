# المخططات الموسوعية العربية

موقع للمخططات الزمنية والأدلة المرجعية الخاصة بتاريخ العالم الإسلامي الحديث، مع تقديم الجزيرة العربية في ترتيب المناطق.

## الأقسام

- الحكام والقادة.
- الحروب والصراعات.
- الفرق والردود، مع نسبة الآراء والنقد إلى أصحابها.
- القادة العسكريون والحركات.
- العلماء والمفتون، مع تمييز التقاليد العلمية بالألوان.

## عن الإعداد

أعددت هذه المخططات والموسوعة التفاعلية بمساعدة تشات جي بي تي لتنظيم المعلومات وترجمتها وعرضها. وهذه نسخة بحثية قابلة للمراجعة، وليست بديلًا عن الرجوع إلى المصادر؛ وتظهر مصادر كل مدخل في تفاصيله.

تعريب النسخة المرجعية السابقة ذات الحد الزمني ٣٠ سبتمبر ٢٠٢٦. التعريب لا يعد مراجعة مستقلة لجميع الوقائع، ولا تأكيدًا جديدًا لاستمرار المناصب أو النزاعات المعاصرة.

## النشر

بعد اكتمال رفع ملفات الموقع، اختر من إعدادات المستودع قسم Pages، ثم النشر من الفرع main والمجلد الجذري. يوضع ملف index.html في جذر المستودع. لا يحتاج العرض إلى تسجيل الدخول أو خدمات تتبع.
